# Homeward sample threads (synthetic)

Fictional email threads for testing Homeward. Every person, company, address, and policy number is made up. The issues are modeled on real problems Palisades rebuild families have reported: the 110% "like-for-like" permit rule (LA Emergency Executive Order 1), Chapter 7A wildfire building code, the Zone 0 ember-resistant buffer, HOA design rules, and insurance "ordinance or law" (code upgrade) coverage disputes.

These files are safe to commit. Real family emails go in `private/`, never here.

The fictional family: the Morrows, rebuilding at 1180 Ridgeview Lane after the fire.

| File | Parties | Planted problem |

| 01-roof-tile.txt | HOA, builder | Reversal: builder agrees, then says it costs extra; HOA reverses |
| 02-city-plan-check.txt | Builder, City | Builder says design qualifies as like-for-like; city says it doesn't |
| 03-code-upgrade-coverage.txt | Insurer | Insurer contradicts its own earlier coverage statement |
